# E-Commerce Sales Analytics Using SQL
---
## Project Overview
This project analyzes e-commerce sales data using SQL to explore sales performance, customer purchasing behavior, and product trends.
The objective is to practice SQL queries and answer business-related questions that are relevant to data analytics.
---
## Project Objectives
- Analyze sales performance and revenue.
- Identify top-performing products.
- Understand customer purchasing behavior.
- Summarize data using aggregate functions.
- Combine related tables using SQL joins.
- Apply advanced SQL techniques to business questions.
---
## Tools and Technologies
- **SQL:** For data analysis and querying.
- **Database:** MySQL
- **SQL Editor:** MySQL Workbench
- **Version Control:** GitHub

## SQL Concepts Covered
- Basic queries: SELECT, WHERE, ORDER BY
- Aggregate functions: SUM, COUNT, AVG
- GROUP BY
- Case When
- SQL joins
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
---
## Business Questions
The project is designed to explore questions such as:
1. What are the highest-performing products?
2. Which products or categories generate the most revenue?
3. How do sales vary across different groups?
4. Which customers contribute the most to sales?
5. What useful patterns can be identified through aggregations and rankings?
---
## How to Explore the Project
1. Open the `data/` folder to find the dataset.
2. Open the `sql-queries/` folder to review the SQL scripts.
3. Start with the basic queries and progress to the advanced queries.
4. Execute the queries in the database software compatible with your scripts.
---
## Key Learnings
- Writing SQL queries to retrieve and filter data.
- Summarizing data using aggregate functions.
- Combining tables through joins.
- Using subqueries, CTEs, and window functions.
- Applying SQL to practical business questions.
